Start the autonomous Microchip ESC workflow in this project. Read `AGENTS.md`,
Git status, all progress/blocker reports, current KiCad sheets/netlists/ERC
reports, and the reference PDF. Select the highest-priority unfinished
achievable task, delegate to `esc-researcher` and/or `esc-engineer`, send
results to `esc-reviewer`, integrate only verified results, run validation, and
update all three progress files. Operate without user interaction: do not ask
questions or request confirmation for ordinary decisions. Investigate
alternative legitimate sources and methods before declaring a blocker.
Continue automatically through research, implementation, review, correction,
validation, and visual comparison. Stop only when completion criteria are met
or an explicit external blocker genuinely makes further progress impossible;
document every remaining difference or limitation.
